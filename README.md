## Combined tools: Python + SQL + Power BI
### Customer Shopping Behaviour Analysis

### Goal
Data analytics project showcasing customer behaviour analysis using Python, SQL, and Power BI.

### Description
This project presents an end-to-end data analytics solution designed to analyse customer shopping behaviour and purchasing patterns. The aim was to identify key trends, customer preferences, purchasing habits, and factors influencing spending behaviour through data analysis, SQL querying, and interactive visualisation.
The project covers the complete analytics lifecycle, including data preparation, exploratory analysis, database querying, dashboard development, reporting, and presentation of findings.

### Skills
Data Cleaning, Exploratory Data Analysis, SQL Analytics, Business Intelligence, Data Visualisation, Dashboard Development, Data Storytelling, Stakeholder Reporting, Presentation

### Technology: 
This project was built using Python (Pandas, NumPy, Matplotlib, Seaborn) for data cleaning, exploration and feature engineering, PostgreSQL for structured SQL analysis, and Power BI for interactive dashboard development and insight visualisation.

### Results and Recommendations
The analysis revealed clear spending patterns across customer groups, with subscribers, loyal customers and express‑shipping users consistently generating higher revenue. Female customers contributed slightly more overall spend, while certain age groups emerged as strong revenue drivers. Several products were highly discount‑dependent, yet a segment of high‑spending customers still used discounts without reducing basket value. Top‑rated and best‑selling products showed strong performance across categories, and loyal customers (5+ purchases) displayed a strong link to subscription uptake. Based on these insights, the business should promote subscription benefits to high‑frequency customers, strengthen loyalty programs to increase repeat purchases, review discount strategies for margin‑sensitive products, highlight top‑rated items in marketing campaigns, and focus targeted efforts on high‑value age groups and express‑shipping users to maximise revenue impact.
